# Arduino Voltage Drop Measurement

Today, I learned some new Arduino concepts and applied them in this project:

- How to connect components using jumper wires and a breadboard.
- How to use Serial Communication.
- How to start the Serial Monitor and display data.
- How Arduino sends data to the computer using a USB cable.
- How to read analog values using Arduino and calculate the voltage drop.

I'm still learning and practicing through simulations. I plan to apply everything in real life once I get my Arduino kit and components.

Always expanding my engineering toolkit! 🚀
